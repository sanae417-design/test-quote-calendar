# Daily Quotes — 製品仕様（初回リリース確定版）

更新日: 2026-08-15  
対象: 初回一般公開（MVP）。後続機能は「将来」として分離する。

この文書が仕様の正本です。実装・見積はこれに合わせます。

---

## 1. 何をつくるか

**Daily Quotes**（日本語表記: デイリークォーツ）

毎日ひとつの名言と短い解説を出し、心に響いたかどうかを残すアプリ。  
カレンダーは製品名ではなく、**過去の日を振り返るためのビュー**である。

ユーザーが直接「今日の気分は？」と答えなくても、  
**どのタイプの言葉にいいねしたか** から、その日に何を求めていたかが残る。

例: カテゴリ「元気がほしい」の名言にいいねした日 → その日は元気が必要だった日。

---

## 2. 初回リリースで採用する案

検討した案と、初回での採用は次のとおり。

| 案 | 初回 | 理由 |
| --- | --- | --- |
| 起動は今日の Daily ビュー | 採用 | 毎日開く画面を最短にする |
| Monthly カレンダーがあり、日付タップで Daily へ | 採用 | 「見た日 / 響いた日」が見える最小の振り返り |
| ローカル事前登録データからランダム表示 | 採用 | サーバー不要。更新DLは将来 |
| 合わなければ変更 | 採用（回数無制限） | 3回以上の有料化は将来。回数は記録だけする |
| 3種スタンプで気分を記録 | 見送り | 入力が重く、自己分析の信号が散る |
| いいねした Quote を別保存（お気に入り一覧） | 見送り | いいね自体が「その日の記録」になる |
| いいねしたカテゴリ色をカレンダーに付ける | 採用 | 自己分析の種を、最小UIで残せる |
| 見ただけ（いいねなし）は薄い色、いいねは濃い色 | 採用 | 開いた日と響いた日を一目で分けられる |
| 月次の自己分析画面 | 見送り | 色付きカレンダーが、その前段になる |

結論: **スタンプや分析ダッシュボードは後回し。いいね × カテゴリ色が初回の核。**

---

## 3. 画面構成

画面は2つだけ。

### 3.1 Daily ビュー（起動画面）

起動時は **端末の今日** を開く。

表示するもの:

- 日付と曜日
- 名言
- 短い解説
- カテゴリ（小さなラベル。色はカレンダーと同じ系統）
- **いいね**（心に響いた）
- **別の言葉**（気分に合わなければ変更）
- Monthly ビューへの導線

今日以外の日（カレンダーから来た場合）:

- その日に残った名言・解説・カテゴリ・いいね状態を表示
- **いいね / 別の言葉は出さない**（過去は閲覧のみ）
- 「今日へ戻る」と Monthly への導線

未来の日付は選べない。未記録の過去日を開いた場合は「この日の記録はありません」と出し、名言は後から割り当てない。

### 3.2 Monthly ビュー

- 月のグリッド（日曜始まり）
- 前月 / 次月。次月は「今日を含む月」より先へは進まない
- 日付タップで、その日の Daily ビューへ
- 今日は枠などで識別する
- 凡例: 未記録 / 見た（薄色） / 響いた（濃色）と、カテゴリ色の意味

セルの色:

| その日の状態 | カレンダー |
| --- | --- |
| アプリを開いていない | 色なし |
| 名言は出したが、いいねしていない | その名言カテゴリの **薄い色** |
| いいねした | その名言カテゴリの **濃い色** |

---

## 4. 名言の出し方（Daily のルール）

1. その日はじめて開いたとき、ローカルデータから **ランダムに1件** を出す。
2. 出した名言はその日の記録として保存する。**再読み込みしても変わらない。**
3. 「別の言葉」で、今の件以外からランダムに引き直す。連続で同じ件は出さない。
4. 引き直すと、その日の名言は新しい件に置き換わる。いいねは **外れる**（新しい件は未評価）。
5. 初回は変更回数に上限なし。回数は記録し、将来の「3回以上は有料」に備える。
6. いいねはトグル。オンで「心に響いた」、オフで「見ただけ」に戻る。
7. 日付の境界は **端末のローカル日付**。日付が変わったら新しい日として 1 から始める。アプリを開いたまま日付が変わった場合も、今日の Daily に切り替える。

「1日1名言」ではなく、**1日1スロット**（今表示している1件が、その日の記録）である。

---

## 5. カテゴリ

初回は **4つ**。色が増えすぎず、あとから自己分析しやすい粒度。

| ID | 表示名 | その言葉が響きやすいとき | カレンダー色の役割 |
| --- | --- | --- | --- |
| cheer | 元気がほしい | 落ち込み、疲れ、元気が出ない | 暖色系 |
| calm | 落ち着きたい | 不安、焦り、頭が騒がしい | 青緑系 |
| forward | 前を向きたい | 挑戦、再起、一歩を出したい | 橙〜琥珀系 |
| accept | 自分を認めたい | 自分を責めている、認められたい | 紫系 |

名言データは必ずこのどれか1つを持つ。複数カテゴリは初回では持たない。

表示名や色味は実装時に調整してよい。ID と「4分類」は変えない。

---

## 6. データ

### 6.1 名言マスタ（アプリ同梱）

初回はアプリに含める。サーバーからの自動更新は将来。

1件の形:

- `id`（安定した識別子。表示順や文言を変えても変えない）
- `quote`（名言）
- `description`（短い解説）
- `category`（上記4つの ID）
- `source`（任意。自作なら空または「オリジナル」）

件数の目安: **24〜40件**（各カテゴリ 6〜10件）。  
著作権上問題ない文言だけを入れる。有名な引用を許諾なく使わない。

形式は JSON を正とする（カテゴリがあるため CSV より向く）。公開用バンドルへの埋め込みは生成物でもよい。

### 6.2 ユーザー記録（端末内のみ）

アカウントなし。`localStorage` に保存する。

1日1件:

- `date`（`YYYY-MM-DD`、ローカル日付）
- `quoteId`
- `liked`（boolean）
- `changeCount`（その日「別の言葉」を押した回数）

端末をまたいだ同期、バックアップUIは将来。  
プライバシー文面で「記録はこの端末にだけ残る」と書く。

---

## 7. 初回に含めないもの

- 3種スタンプ、自由記述の日記
- お気に入り一覧、検索、カテゴリ絞り込み
- 月次自己分析（「今月は元気がほしいが多かった」等の集計画面）
- 「別の言葉」の回数制限・有料化
- 名言のネット更新・自動DL
- ログイン、クラウド保存
- シェア、画像保存、PWA、ダークモード
- 未来日の先取り表示
- 過去日のあと乗せ・あといいね

これらは、初回の「いいね × カテゴリ色」の上に載せる。

---

## 8. 将来機能（仕様の延長として予約）

実装しないが、データ形は壊さない。

1. **変更回数の制限 / 有料化**  
   `changeCount` を見て、4回目から制限する。
2. **名言データの自動更新**  
   同梱 JSON をリモートで差し替える。`id` は維持する。
3. **月次自己分析**  
   その月の「いいねしたカテゴリ」の件数・割合を出す。  
   薄い色（見ただけ）は参考、濃い色（いいね）を主指標にする。
4. **スタンプ**  
   いいねを、より細かいリアクションに拡張する余地を残す。初回の `liked` は「最も強い肯定」として移行できる。
5. **お気に入り一覧**  
   `liked === true` の日の名言を列挙する。

---

## 9. 非機能（初回）

- 静的サイト。サーバー処理なし
- 主要ブラウザの最新版、スマートフォン幅を優先
- 名言は `textContent` で描画し、HTML は埋め込まない
- 動きは `prefers-reduced-motion` を尊重する
- 日付変更を、起動時とタブ復帰時に見る
- 管理用の更新ツールは公開ディレクトリに置かない

---

## 10. 文言の目安（初回）

実装時に磨いてよい。意味はこのまま。

| 場所 | 文言 |
| --- | --- |
| いいね（オフ） | 心に響いた |
| いいね（オン） | 響いた |
| 変更 | 別の言葉 |
| 未記録の日 | この日の記録はありません |
| 凡例・見た | 見た |
| 凡例・いいね | 響いた |

アプリ名は **Daily Quotes**。旧称「今日の名言カレンダー」は使わない。

---

## 11. 初回リリースの完了条件

次が揃ったら初回公開してよい。

- Daily と Monthly が行き来できる
- 今日の名言が保存され、再表示しても変わらない
- 「別の言葉」と「いいね」が今日だけ使える
- カレンダーが「未記録 / 薄いカテゴリ色 / 濃いカテゴリ色」になる
- 過去日は閲覧のみ
- 名言は権利上問題ない 24件以上、4カテゴリに分かれている
- 記録は端末内のみである旨が書いてある
- スマートフォンで一通り操作できる
