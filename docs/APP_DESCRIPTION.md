# Daily Quotes — 機能説明

（1000文字以内。仕様の要約。正本は [SPEC.md](SPEC.md)）

Daily Quotesは、毎日ひとつの名言と短い解説を届け、心に響いた言葉を残すアプリです。

起動すると今日の画面が開きます。まだ出していない名言から1件が選ばれ、その日の言葉として保存されます。同じ名言は、一通り出るまで繰り返しません。合わなければ引き直す機能は、初回にはありません。

響いたら「いいね」できます。いいねした日はカレンダーに濃い色、見ただけの日は薄い色が付きます。色は名言のタイプ（元気がほしい／落ち着きたい／前を向きたい／自分を認めたい）で変わります。どのタイプにいいねしたかが、その日に何を求めていたかの記録になります。

カレンダーから過去の日を開くと、その日に出た名言を見返せます。過去の日のいいねはいじれません。画面の端から、これまでにいいねした名言をカード一覧で見られます。

名言にはマスタ全体で一つだけのIDが付いています。端末の記録も同じIDを使います。出した日の本文は端末にコピーして残すので、あとから名言データが更新されても、その日の言葉は変わりません。記録はこの端末にだけ残り、最大100日分です。それを超えると古い日から消えます。ログインは不要です。
