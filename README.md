# Daily Quotes

毎日ひとつの名言と短い解説を出し、心に響いた言葉を残す静的Webアプリ。

- ユーザー画面: `index.html`
- 名言マスタ: `data/202608_01.csv`（ID は `202608_01` 〜 `202608_30`）

ローカル確認:

```bash
python3 -m http.server 8080
```

`http://localhost:8080` を開きます。
